Cara Bina Dalam Google Sheets / Excel & Google Apps Script

Selain menggunakan aplikasi web ini secara terus, anda juga boleh menyalin formula atau skrip di bawah terus ke dalam fail Google Sheets sekolah anda.

1 Kaedah Paling Mudah: Formula Terus Dalam Google Sheets / Excel

Andaikan struktur Google Sheet anda mempunyai lajur berikut: Lajur A (Nama Murid), Lajur B (Kelas), Lajur C (Nama Waris), dan Lajur D (No. KP Waris).

Formula Lajur E: Kira Bilangan Anak
=COUNTIF(D:D, D2)

Mengira berapa kali No. KP Waris pada sel D2 berulang dalam keseluruhan Lajur D.

Formula Lajur F: Status Lebih 1 Anak
=IF(COUNTIF(D:D, D2)>1, "Lebih 1 Anak ("&COUNTIF(D:D, D2)&" Orang)", "Anak Tunggal Di Sekolah")

Memaparkan label secara automatik sama ada waris mempunyai lebih dari seorang anak.

Formula Tambahan: Menentukan Wakil Kutipan PIBG (1 Keluarga = 1 Bayaran)
=IF(COUNTIF($D$2:D2, D2)=1, "WAKIL KELUARGA (BAYAR)", "DIKECUALIKAN (ADIK-BERADIK)")

Formula ini memastikan hanya anak pertama dalam senarai ditandakan sebagai WAKIL KELUARGA manakala adik-beradik lain yang berkongsi No. KP Waris yang sama ditandakan sebagai dikecualikan!

2 Skrip Automasi Google Sheets (Google Apps Script)

Buka Google Sheets anda, klik Extensions > Apps Script, tampal kod di bawah untuk menjana jadual ringkasan keluarga secara automatik (termasuk padanan silang No. KP Bapa dan Ibu):

/**
 * Fungsi Google Apps Script untuk mengenalpasti waris yang mempunyai
 * lebih daripada seorang anak di sekolah (Menyokong Padanan KP Bapa & Ibu)
 */
function janaLaporanWarisLebihSatuAnak() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheetMurid = ss.getSheetByName('Data_Murid'); // Pastikan nama sheet betul
  
  if (!sheetMurid) {
    SpreadsheetApp.getUi().alert('Sila pastikan terdapat sheet bernama "Data_Murid"!');
    return;
  }

  const data = sheetMurid.getDataRange().getValues();
  const petaKeluarga = {};

  // Andaian Lajur: [0]Nama Murid, [1]MyKid, [2]Kelas, [3]Nama Bapa/Waris1, [4]KP Bapa/Waris1, [5]Nama Ibu/Waris2, [6]KP Ibu/Waris2, [7]No Telefon
  for (let i = 1; i < data.length; i++) {
    let namaMurid = data[i][0];
    let mykid     = String(data[i][1]).replace(/[-\s]/g, '');
    let kelas     = data[i][2];
    let namaWaris = data[i][3] || data[i][5];
    let kpBapa    = String(data[i][4] || '').replace(/[-\s]/g, '');
    let kpIbu     = String(data[i][6] || '').replace(/[-\s]/g, '');
    let noTel     = String(data[i][7] || '');

    if (!namaMurid) continue;

    // Gunakan KP Bapa sebagai kunci utama, jika tiada guna KP Ibu
    let kunciKeluarga = kpBapa !== '' ? kpBapa : kpIbu;
    if (!kunciKeluarga) continue;

    if (!petaKeluarga[kunciKeluarga]) {
      petaKeluarga[kunciKeluarga] = {
        namaWaris: namaWaris,
        kpWaris: kunciKeluarga,
        noTel: noTel,
        anak: []
      };
    }
    petaKeluarga[kunciKeluarga].anak.push(namaMurid + ' (' + kelas + ')');
  }

  // Cipta atau kemaskini Sheet Laporan
  let sheetLaporan = ss.getSheetByName('Laporan_Waris');
  if (!sheetLaporan) {
    sheetLaporan = ss.insertSheet('Laporan_Waris');
  } else {
    sheetLaporan.clear();
  }

  // Bina Header
  sheetLaporan.appendRow([
    'No. KP Waris', 'Nama Waris', 'No. Telefon', 
    'Bilangan Anak', 'Status', 'Senarai Anak & Kelas'
  ]);

  // Masukkan Data
  Object.values(petaKeluarga).forEach(kel => {
    let bil = kel.anak.length;
    let status = bil > 1 ? 'LEBIH 1 ANAK (' + bil + ' ORANG)' : '1 ANAK SAHAJA';
    sheetLaporan.appendRow([
      "'" + kel.kpWaris,
      kel.namaWaris,
      "'" + kel.noTel,
      bil,
      status,
      kel.anak.join(', ')
    ]);
  });
}

Sambungan Automatik Google Sheets (Live Auto-Sync)

Bagaimana Auto-Sync Ini Berfungsi?

Apabila disambungkan, setiap kali Admin menambah atau mengemaskini nama murid/waris di dalam Google Sheets, sistem ini akan menarik data terkini secara automatik tanpa perlu muat naik fail berulang kali!

Langkah Mudah Di Google Sheets Anda:

  1. Buka Google Sheets sekolah anda dan pastikan 8 lajur pertama ialah:
    A: Nama Murid | B: MyKid | C: Kelas | D: Nama Bapa | E: KP Bapa | F: Nama Ibu | G: KP Ibu | H: No Telefon
  2. Klik menu Share (Kongsi) di penjuru kanan atas Google Sheets → Tukar General Access kepada "Anyone with the link" (Viewer), ATAU klik File → Share → Publish to web (CSV).
  3. Salin pautan (Link URL) Google Sheets tersebut dan tampal di ruang bawah:

Anda boleh tampal link penuh Google Sheets biasa, sistem akan menukarkannya kepada pautan bacaan data secara automatik.
